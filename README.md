# SillyTavern-QuickCharRegex

**SillyTavern-QuickCharRegex** is a productivity extension designed for SillyTavern users. It provides a streamlined way to perform bulk text replacements—using either simple text or Regular Expressions (Regex)—directly within the character editing interface.

## Features

* **Multi-Field Targeting:** Perform quick replacements on Description, First Message, Dialogue Examples, Scenario, or Personality fields.
* **Regex Support:** Use powerful Regular Expressions for complex pattern matching and text manipulation.
* **Simple Replace:** A "Simple" mode for straightforward string swapping without worrying about regex syntax.
* **Undo Functionality:** Quickly revert the last replacement if the results weren't what you expected.

---

## Installation and Usage

### Installation

1. Open SillyTavern and go to the **Extensions** menu.
2. Select **Install Extension**.
3. Paste the URL of this repository (`https://github.com/Venomkajo/SillyTavern-QuickCharRegex`) and click **Install**.

### Usage

1. **Locate the Tool:** Look for the new **Quick Char Regex icon** located in the **Character Management** section (the area with avatar controls and upload buttons).
2. **Open the Menu:** Click the button to toggle the Regex replacement interface.
3. **Configure:** * Select your **Method** (Simple, Regex, or Whole-Words).
    * Select the **Field** you wish to modify.
4. **Replace:** Enter the **Pattern** you want to find and the **Replacement** text, then click **Replace**.
5. **Undo:** If you make a mistake, click the **Undo** button to immediately restore the previous text for that field.
